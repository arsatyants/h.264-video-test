Latency = UDP receive time on host - sensor timestamp (host clock via NTP + UDP ping-pong offset, ~9-10 ms measured, subtracted). Target bitrate 8 Mbit/s.
drift = median latency in last 3 s minus first 3 s of the 8 s window (growth => buffer accumulating). rx/tx fr = frames received / frames produced.
